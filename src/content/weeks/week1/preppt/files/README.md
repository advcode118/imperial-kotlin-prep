# Library catalogue API: practice exercise

A practice exercise in the style of an Imperial lab. It is not an official exercise.

- `src/main/kotlin/Http.kt`: provided types. Read it; do not change it.
- `src/main/kotlin/Library.kt`: your code. Replace each `TODO()`.
- `src/test/kotlin/LibraryTest.kt`: the tests. Only the first is live; uncomment the others one at a time.

## Running the tests

**IntelliJ IDEA.** Open this folder as a project (it is a Gradle project, so IntelliJ will import
`build.gradle.kts` and fetch what it needs). Open `LibraryTest.kt` and use the green arrow next to the
class or a single test.

**Command line.** With a JDK and `kotlinc` installed, run `./build.sh`. It compiles everything and runs the
tests with JUnit. The first run downloads the JUnit jars into `lib/`.

The full exercise text, a timer and worked solutions are on the site this file came from.
